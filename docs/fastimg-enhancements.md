# FastImg 增强功能实施说明

本阶段把 Nodeimage 参考方案中适合 FastImg 的能力落地为可验证的业务边界。普通上传仍然立即生成可用链接；安全检测是上传完成后的异步任务，只有高风险结果才自动隐藏并进入管理员治理，不把所有用户上传变成待审核队列。

## 已纳入范围

- 网页、拖拽、剪贴板、Personal API Token、curl、PicGo、ShareX 和 CLI 共用同一上传契约。
- URL、Markdown、HTML、BBCode 链接统一由服务端生成，域名来自 `APP_URL`/公开站点配置。
- 上传安全基线：真实文件格式、文件魔数、像素数量、动画帧数、解码大小和 EXIF 清理。
- 安全扫描任务：上传成功后异步检查对象；普通结果保持公开，高风险结果转私有并产生治理任务。
- 原图单份保存；派生尺寸采用按需生成和可清理缓存的 Variant 边界，不在上传时固定生成三份文件。
- 图片生命周期：用户过期时间、到期提醒、回收站保留和永久删除沿用现有用量释放流程。
- 发现页支持最新、热门、趋势排序、举报和管理员处理；标签需要补充媒体标签数据模型后再启用，避免用文件名或假数据冒充标签。
- 公开 `/status` 状态页和管理员维护公告。
- 用户媒体导出：原图、JSON 元数据、链接清单、文件夹/相册关系和导出进度。
- 客户端接入：网页、拖拽、Ctrl+V、`/api/v1/uploads`、兼容 `/api/upload`、PicGo、ShareX、curl 和 CLI 共用 Personal API Token 权限边界。

## 外部能力边界

WebP/AVIF 编码、NSFW/恶意文件云扫描、CDN 缓存刷新、国家/地区识别和云厂商账单必须通过明确 Provider 接口接入。当前本地扫描已覆盖魔数、声明类型、解码像素上限、危险签名和 EXIF 清理；WebP/AVIF、外部 NSFW/恶意文件扫描、CDN 刷新和云账单尚未接入真实 Provider。没有真实 Provider 时，系统只能报告“未配置/不可用”，不能伪造成功或账单数据。

## 安全约束

- 图片上传完成后默认 `visibility=public`、`moderation_status=approved`。
- 扫描高风险只执行自动隐藏和创建待处理任务，不自动永久删除。
- 变体请求必须校验原媒体归属、公开性、套餐权限、宽高上限和缓存键；私有媒体不得进入公共缓存。
- 导出任务只能访问当前用户媒体，压缩包放在私有目录，下载必须经过认证和一次性任务授权。
- 状态页只返回组件健康状态、维护信息和更新时间，不返回凭证、内部地址或异常堆栈。

## 生产门禁

真实 Redis 消费/失败重试、隔离环境恢复演练、对象存储/CDN 实测、外部安全扫描、国家/地区统计、邮件发送和压力测试完成后，才可以把对应功能标记为生产可用。
