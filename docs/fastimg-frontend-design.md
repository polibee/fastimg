# FastImg 前端页面与交互设计

## 1. 前端边界

FastImg 前端分为两套体验：

```text
用户端：上传、媒体管理、分享、Token、套餐和用量
管理端：用户、媒体、审核、套餐、广告、任务和统计
```

用户端业务页面位于 `admin/src/modules/<name>`；通用认证、布局、通知、权限和 Resource 页面复用现有 `admin/src/core` 与 `admin/src/components`。

两套体验可以先共用仓库、Vite 构建和框架基础能力，但必须使用独立路由区、布局、导航和访问策略；“共用代码”不等于“共用页面”或“共用权限”。

| 维度 | 用户端 / 会员中心 | 管理端 / 运营后台 |
| --- | --- | --- |
| 用户 | 普通注册会员 | 具备对应后台 RBAC 权限的管理员/运营人员 |
| 页面布局 | `MemberShell`，面向上传和个人资产 | `AdminShell`，面向全站配置和运营管理 |
| 路由 | `/`、`/media`、`/plans`；公开发现页 `/discover` | `/admin/**`；不能把会员页当成后台管理页 |
| 数据范围 | 只能查看和操作当前登录用户自己的媒体、Token、订单及用量 | 通过独立后台权限查询跨用户数据，并对敏感查看和操作审计 |
| API | 用户身份从认证上下文取得；忽略或拒绝客户端指定的 `user_id` | `/api/v1/admin/**` 等管理接口执行 RBAC、数据范围和审计 |
| 核心任务 | 上传、个人媒体管理、复制各种链接、套餐/用量、个人 Token | 管理会员/套餐/广告/站点设置、按用户查媒体、举报审核、统计与任务恢复 |

### 功能关联与职责交接

| 业务域 | 用户端行为 | 管理端行为 | 共享的服务端事实 |
| --- | --- | --- | --- |
| 上传/媒体 | 创建上传、管理自己的图片、复制链接、删除/恢复 | 按用户/状态查媒体，按权限审核、隐藏、恢复或处理违规 | 同一 MediaAsset/Variant/StorageObject 与配额、审计；用户归属由服务端强制 |
| 套餐/用量 | 查看 Free/付费权益和自身额度，按额度使用功能 | 维护套餐、权益版本和会员订阅，处理额度调整 | Plan/Subscription 快照和服务端 UsageLedger；前端不能自行计量或改额度 |
| Token/API | 为本人创建/撤销 Token，通过 API 上传并获取自己的链接 | 仅按独立管理权限处理滥用或安全事件，不读取明文 Token | token hash、调用身份、归属校验、速率/配额与审计；Token 明文仅创建时展示一次 |
| 发现/举报 | 浏览公开审核通过内容，投稿/举报并查看本人申诉 | 开关发现页/投稿，处理举报和申诉，执行有期限/原因的处罚 | 同一审核状态、Report、ModerationAction 和审计；举报数本身不自动永久封号 |
| 广告/统计 | 只读展示管理员启用的页眉、页脚、左侧栏或右侧栏广告；查看个人用量/访问摘要 | 管理四类固定广告位、文本/图片/JS 内容、跳转地址和启停 | 后端决定广告展示资格；广告活动、竞价和点击统计暂不进入简单 MVP |

会员资料管理是“管理自己的账号与安全设置”，不是会员管理其他账号；用户列表、封禁、角色和全站套餐管理只属于后台。

实现时复用 Go Vue Admin 的认证、API Client、i18n、基础组件和服务层；不要复制一套认证/RBAC，也不要让普通会员进入 `AdminShell`。成员端读写都必须在服务端按当前身份做 owner-scope 校验；管理员跨用户访问只能走显式授权的管理用例，并记录审计。套餐权益限制会员可用额度/功能，不授予管理员权限。

当前代码状态需要与设计状态区分：会员端现已作为 `admin/` 同一 Vue 工程内的独立路由分支落地：`/` 使用 `MemberShell`，提供上传优先首页、最近本人媒体和套餐/存储摘要；`/media` 提供本人图片上传、媒体列表/预览、搜索、软删除和回收站恢复；`/media/:id` 提供本人媒体只读详情、认证链接复制、可选密码/过期时间的分享链接、签名 URL 生成和基础防盗链策略维护；`/folders`、`/albums` 提供本人文件夹/相册基础 CRUD；`/share-links` 管理本人分享链接摘要和撤销；`/tokens` 提供 Personal API Token 创建、一次性展示、撤销和轮换；`/plans` 读取公开套餐目录、当前登录人的订阅和本人用量。首页和媒体库共用上传组件及状态轮询，不提交 `user_id`；服务端从认证身份解析所有者。管理首页、RBAC、审计、全站资源和媒体访问记录查询均位于 `/admin/**`，其中 `/admin/media-access-logs` 只对 `admin.media_access_logs.view` 开放并展示脱敏字段。旧 `/app`、`/app/media`、`/app/plans` 静态重定向到新会员路径。文件夹/相册后台资源仍由管理员页面管理，但会员端使用独立 `/api/v1/me/folders`、`/api/v1/me/albums` API，不依赖管理员权限；媒体到文件夹的本人归档接口和 Personal API Token 后端基础认证已实现，媒体到相册关联、CDN 原生防盗链、带宽计量、媒体编辑/批量操作、订单和发现页仍待后续切片。认证链接和普通分享链接已区分；分享密码由服务端 Hash 并在公开访问时校验，应用层签名 URL、Referer 策略和访问记录已经完成本地数据库迁移、重启和真实 HTTP 验收。共享 Vite、认证、API Client、vue-i18n 和 shadcn-vue 不代表共用页面或管理权限。

范围约束已经落到实现：`/api/v1/me/folders` 与 `/api/v1/me/albums` 永远按认证用户 own-scope 执行；`/api/v1/admin/folders` 与 `/api/v1/admin/albums` 使用后台权限和 all-scope，面向管理员查看/管理所有用户的容器数据。前端生成资源的 `dataScope: all` 只用于后台资源页，不会改变会员端 API 的所有权校验。`/folders`、`/albums` 与 `/admin/folders`、`/admin/albums` 是两套页面，不能通过旧版平铺重定向互相覆盖。

## 3. 上传工作台

### 3.3 订单与支付页面

#### 3.3.1 套餐购买

- 套餐卡片显示价格、货币、计费周期、权益、优惠前后金额和下次续费时间。
- 订单确认页显示套餐版本、权益快照、优惠码结果、应付金额和服务条款确认。
- 支付渠道由服务端返回可用列表；前端不自行判断渠道是否支持当前货币或地区。
- 创建订单按钮必须防重复提交，使用幂等请求并在支付中状态下禁用重复创建。

#### 3.3.2 支付状态

```text
订单创建 -> 待支付 -> 支付处理中 -> 已支付 -> 权益发放中 -> 已生效
                         |              |
                         v              v
                       失败/重试       履约失败/联系客服
```

用户必须能看到订单号、支付渠道、金额、支付结果、权益生效时间和安全摘要错误；不能因刷新页面重复扣款或重复激活套餐。

#### 3.3.3 订单和账单

- 订单列表支持按状态、时间和套餐筛选。
- 订单详情展示商品快照、价格、折扣、支付流水摘要、退款状态和权益关联。
- 提供账单/收据下载入口；税务发票状态单独展示，不能把收据冒充发票。
- 支付成功但权益尚未生效时展示“正在发放权益”，提供刷新和联系客服入口。

### 3.1 页面区域

```text
顶部：当前套餐、存储用量、流量用量、升级入口
中部：拖拽/选择/粘贴上传区域
设置：可见性、文件夹、相册、标题、标签、过期时间
队列：文件名、缩略图、进度、状态、重试、取消
底部：链接复制和批量操作
```

### 3.2 文件状态

| 状态 | UI 表现 | 用户操作 |
| --- | --- | --- |
| waiting | 等待上传 | 取消 |
| uploading | 进度条和速度 | 暂停/取消 |
| processing | “正在生成图片链接” | 查看详情 |
| ready | 成功图标和复制按钮 | 复制链接、查看、删除 |
| failed | 错误码和原因 | 重试、移除 |
| rejected | 审核/格式拒绝原因 | 查看规则、移除 |

前端不得因为上传 HTTP 请求成功就显示“完成”；必须根据媒体状态或处理查询接口显示 `ready`。

### 3.3 上传成功后的链接展示（2026-09-24）

会员首页 `/` 和媒体库 `/media` 共用 `MemberUploadPanel`。当上传接口或状态轮询返回 `ready` 且服务端返回 `links` 时，队列项立即展开四种可复制格式：纯 URL、Markdown、HTML、BBCode。复制操作只写入用户主动选择的剪贴板内容，并显示短暂的成功反馈；链接生成、Variant 和所有权仍由后端 `media.Links` Service 决定，前端不拼接链接、不接受 `user_id`。

当前这些上传后链接复用认证内容端点，适合当前登录会员获取自己的图片链接；它们不是绕过权限的公开稳定链接。公开分享、密码分享、签名 URL 和防盗链策略仍按媒体详情页及 M3 访问策略执行。处理中的图片没有 `links` 时只显示处理中状态，不展示失效地址。

### 3.4 配额提示

上传前展示：

- 当前文件大小
- 上传后预计使用量
- 当前剩余空间
- 今日剩余上传次数
- 当前 Token/API 配额（如果使用 Token）

超额提示必须明确原因，例如“空间不足 120 MB”，并提供删除旧文件、清空回收站或升级套餐入口。

## 4. 媒体库

### 4.1 网格卡片

卡片展示：

- 缩略图
- 文件名/标题
- 尺寸和大小
- 状态标签
- 可见性
- 选择框
- 快捷复制 URL

不要在网格中加载原图；缩略图失败时展示可重试的占位状态。

### 4.2 批量操作

批量操作必须显示选择数量和影响范围：

- 移动到文件夹
- 添加到相册
- 修改可见性
- 创建分享链接
- 下载
- 移入回收站

永久删除、批量公开和批量下载必须二次确认。操作结果使用 `succeeded`、`failures`、`skips` 分组展示，不能只显示一个“操作成功”。

## 5. 媒体详情页

页面分为四个区域：

1. 预览：缩略图、中图、原图切换。
2. 链接：URL、Markdown、HTML、BBCode、原图和各 Variant。
3. 信息：文件名、MIME、大小、尺寸、哈希、上传时间、可见性。
4. 操作：编辑、创建分享、下载、删除、恢复。

链接组件规则：

- `null` Variant 显示“处理中”，不显示失效 URL。
- 每个链接独立复制，并提供复制成功反馈。
- Markdown/HTML 中的标题来自用户标题，必须进行转义。
- 原图下载和批量下载根据套餐权益显示或禁用。
- 复制链接不应把密码或 Token 写入剪贴板之外的日志。

## 6. Personal API Token 页面

### 6.1 Token 列表

表格列：

```text
名称 | 前缀 | 基础能力 | 扩展 Scope | 状态 | 过期时间 | 最近使用 | 操作
```

完整 Token 不在列表显示。创建成功后显示一次性安全提示框：

```text
请立即复制 Token。离开此页面后无法再次查看完整 Token。
```

### 6.2 创建表单

表单包含：

- Token 名称（必填）
- 过期时间（可选）
- 可选 Scope：媒体列表、用量、Webhook
- 风险提示：Token 等同于个人 API 凭证

上传、获取自己图片链接和删除自己图片是固定基础能力，不显示为可取消的复选框。

### 6.3 撤销和轮换

- 撤销前显示最近使用时间和来源 IP。
- 轮换明确提示旧 Token 会立即失效。
- 删除/撤销成功后清除前端内存中的 Token。
- Token 页面不能把完整 Token 写入 URL、LocalStorage 或埋点事件。

## 7. 用量和套餐页面

用量卡片：

```text
存储空间：已用 / 总量
外链流量：本周期已用 / 总量
每日上传：今日已用 / 上限
API 上传：本周期已用 / 上限
图片处理：本周期已用 / 上限
```

每张卡片必须显示重置时间或“长期额度”。套餐比较只突出差异，不隐藏 Free 的已拥有能力。

## 8. 回收站和删除体验

- 删除先进入回收站，不立即物理删除。
- 回收站显示预计永久删除时间。
- 恢复前检查原对象和用户当前配额。
- 永久删除明确说明原图、派生图和分享链接都会失效。
- 回收站内容继续计入存储用量，页面必须明确提示。

## 9. 发现页

- 首次加载先请求 `/api/v1/discovery/status`；关闭时显示后台配置的关闭说明，不继续请求 feed。
- 默认只请求 approved、ready、public 媒体。
- 投稿按钮受 `submissions_enabled` 控制，关闭时显示“当前暂停投稿”。
- 瀑布流使用分页或游标，不一次加载全部数据。
- 支持随机、最新、热门排序，但排序参数必须由后端白名单控制。
- 卡片提供举报入口，不展示 GPS/EXIF 等隐私信息。
- 未登录用户只能浏览公开内容，不能访问私有媒体。

发现页状态：

| 状态 | 用户端行为 | 后台行为 |
| --- | --- | --- |
| enabled | 展示内容和投稿入口 | 审核新投稿和举报 |
| submissions_closed | 展示已有内容，不显示投稿入口 | 继续处理已有举报 |
| disabled | 展示关闭说明，不请求内容列表 | 仍可审核、举报和恢复 |

举报弹窗必须提供原因、补充说明和提交结果。用户不能看到被举报人的私密信息，管理员处理结果通过通知反馈必要信息。

## 10. 管理端页面

AdminShell 顶栏提供双语“前往用户端”快捷入口，导航到会员首页 `/` 并由 `MemberShell` 承载；此链接仅切换页面，不修改账号身份或权限。

### 10.1 发现页设置

- 总开关：启用/停用发现页
- 投稿开关：允许/禁止新图片投稿
- 审核模式：人工、自动、混合
- 默认排序：最新、随机、热门
- 举报阈值：达到阈值后自动进入人工复核
- 关闭提示文案

修改设置前显示影响范围；停用发现页不影响用户私有媒体和已有私有分享链接。

### 10.2 举报处理工作台

列表支持按状态、原因、媒体、用户、时间筛选。详情展示媒体预览、用户摘要、举报历史、审核结果和相关处罚记录。

处理动作：

- 驳回举报
- 隐藏图片
- 删除图片
- 恢复图片
- 限制用户投稿
- 限制用户上传
- 暂停账户
- 封禁账户

每个动作必须填写原因；封禁、永久删除和批量操作必须二次确认并写入审计日志。

处罚弹窗必须显示：

- 处罚对象和影响范围
- 当前违规图片和举报原因
- 处罚级别：限制投稿、限制上传、暂停、封禁
- 处罚期限
- 是否立即隐藏已有公开图片
- 是否允许申诉

不能把“举报次数”直接展示成自动封禁依据；达到阈值时显示“需要人工复核”。

### 10.3 用户申诉

被处罚用户在个人中心看到：

```text
处罚类型 | 原因 | 生效时间 | 到期时间 | 状态 | 申诉入口
```

申诉表单包含说明和证据附件。提交后显示 `pending/reviewing/upheld/overturned/adjusted` 状态，并通过通知告知最终结果。

管理端优先复用 Generic Resource：

- 套餐
- 套餐权益
- 文件夹/相册
- 广告位/广告素材
- 举报
- 存储节点
- Personal API Token 运营列表（按用户查看、状态管理和使用元数据）

使用 Custom Page：

- 运营仪表盘
- 全局媒体审核
- 用户媒体详情
- 失败任务中心
- 流量和收入分析

管理员页面必须显示数据来源时间和筛选条件；涉及用户媒体、额度、封禁、审核和永久删除的操作必须显示审计提示。

Personal API Token 的管理端与会员端严格分离：会员端 `/tokens` 只管理当前用户并且只在创建/轮换时显示一次完整 Token；管理端 `/admin/api_tokens` 只展示非秘密运营字段，不能创建、读取或导出完整 Token/token_hash，也不能物理删除 Token，只能通过受权限保护的状态动作停用或撤销。

## 11. 空状态、错误和可访问性

- 空媒体库：说明如何上传，并提供上传按钮。
- 无搜索结果：显示当前筛选条件和清除筛选按钮。
- API/网络错误：显示 request ID 和重试按钮。
- 403：说明权限或套餐原因，不泄露资源是否存在的敏感信息。
- 429：显示限流/配额原因和下次可重试时间。
- 所有上传进度、状态颜色和按钮都要有文本或 aria-label，不依赖颜色表达唯一含义。
- 键盘可以完成文件选择、复制链接、删除确认和 Token 撤销。

会员端广告布局保持轻量：页眉和页脚占用独立的窄行，左右广告仅在宽屏显示，不使用明显的 Card/阴影容器。广告通过认证后的 `GET /api/v1/ads?placement=...` 读取；文本使用插值渲染，图片使用 `img`，JavaScript 使用 `sandbox="allow-scripts"` 且不授予 `allow-same-origin`。广告写入仍只走管理员 Generic Resource 和广告 Service 的校验。

后台广告表单使用共享 Resource Form 的多行输入能力：`creative_content` 显示为带说明的 textarea，输入区域使用等宽字体，管理员可直接看到“文本输入 / 图片 URL / JavaScript 源码”的填写位置；JavaScript 不需要也不允许粘贴 `<script>` 外壳。

## 游客与会员端访问边界（2026-09-24）

- `/` 是公开的上传首页壳层：游客可以查看首页、广告和产品说明，但上传区域只显示“登录后上传”，不会打开文件选择器或发起上传请求。
- `/plans` 是公开的套餐目录：游客可查看套餐权益；订阅状态、存储/流量用量和当前套餐只在登录后加载。
- `/media`、`/media/:id`、`/folders`、`/albums`、`/share-links`、`/tokens` 仍是当前账户页面，未登录访问统一跳转 `/login?redirect=...`。
- 前端路由公开只改善展示边界，上传接口继续由后端会员认证中间件保护；未认证 `POST /api/v1/uploads` 仍返回认证错误。链接读取、删除和其他媒体操作继续沿用当前用户/Token 的所有者范围。
- 会员壳层游客导航只保留首页和套餐，登录后才显示个人媒体、整理、分享和开发者工具入口；管理员入口只对具备管理权限的登录用户显示。

### 开发预览样式运行约束（2026-09-24）

- FastImg 隔离 Vite 配置必须保留 `@tailwindcss/vite` 插件；仅导入 `style.css` 会生成 Tailwind reset/主题变量，但不会生成页面使用的 utility classes，表现为页面结构存在而样式全部丢失。
- Windows 开发机若缺少 `@tailwindcss/oxide-win32-x64-msvc` 可选原生包，不能通过删除 Tailwind 插件规避；应恢复同版本本地依赖后再启动。当前运行态使用 `admin/vite.fastimg-isolated.config.mjs`、Vite `53083`，API 后端为 `53084`。

### 会员导航紧凑化（2026-09-24）

- 会员导航按钮使用 `member.nav.*` 短标签，页面标题仍保留完整语义；例如“我的图片”在导航中显示为“图片”，`Personal API Token` 显示为 `API`。
- 每个短标签链接保留完整的 `aria-label` 和 `title`，不以缩短文案牺牲屏幕阅读器和悬停提示；路由、权限、导航顺序和管理端 `/admin/**` 不变。
- 导航容器使用窄屏横向滚动和不换行布局，品牌文字在小屏隐藏但保留可访问名称，避免登录、语言切换和退出按钮被挤出视口。

### 管理端账务页面（2026-09-24）

- `/admin/orders`、`/admin/payment-transactions`、`/admin/payment-events` 和 `/admin/refunds` 是管理员账务查询页面，不会注册到会员端根路由。
- 页面只展示订单号、用户 ID、渠道、金额、状态、时间和脱敏事件元数据；价格快照、签名、密钥和完整回调 payload 不直接展示。
- 页面访问分别受 `admin.orders.view`、`admin.payment_transactions.view`、`admin.payment_events.view` 和 `admin.refunds.view` 守卫；后端权限仍是最终裁决。
- 当前为查询型页面，退款审批、履约重试和对账差异处理继续通过后端专用 Service/Action 扩展，不允许通用表单直接修改财务事实。
