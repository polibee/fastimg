# FastImg 前端页面与交互设计

## 1. 前端边界

FastImg 前端分为两套体验：

```text
用户端：上传、媒体管理、分享、Token、套餐和用量
管理端：用户、媒体、审核、套餐、广告、任务和统计
```

用户端业务页面位于 `admin/src/modules/<name>`；通用认证、布局、通知、权限和 Resource 页面复用现有 `admin/src/core` 与 `admin/src/components`。

## 2. 用户端路由

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/app` | 用户首页 | 上传入口、用量摘要、最近媒体 |
| `/app/upload` | 上传工作台 | 单图、多图、分片、进度和失败重试 |
| `/app/media` | 媒体库 | 网格/列表、搜索、筛选和批量操作 |
| `/app/media/:id` | 媒体详情 | 预览、各种链接、元数据和统计 |
| `/app/folders` | 文件夹 | 文件夹树、移动和批量整理 |
| `/app/albums` | 相册 | 相册、封面、排序和访问策略 |
| `/app/share-links` | 分享链接 | 创建、复制、撤销和过期状态 |
| `/app/tokens` | Personal API Token | 创建、显示一次、撤销和轮换 |
| `/app/usage` | 用量 | 存储、流量、上传、API 和处理量 |
| `/app/plans` | 套餐 | Free/Creator/Pro 对比和升级 |
| `/app/orders` | 订单 | 订单状态、周期和支付结果 |
| `/app/trash` | 回收站 | 恢复和永久删除 |
| `/discover` | 发现页 | 公开且审核通过的媒体 |

## 3. 上传工作台

### 3.3 订单与支付页面

#### 3.3.1 套餐购买

- 套餐卡片显示价格、货币、计费周期、权益、优惠前后金额和下次续费时间。
- 订单确认页显示套餐版本、权益快照、优惠码结果、应付金额和服务条款确认。
- 支付渠道由服务端返回可用列表；前端不自行判断渠道是否支持当前货币或地区。
- 创建订单按钮必须防重复提交，使用幂等请求并在支付中状态下禁用重复创建。

#### 3.3.2 支付状态

```text
订单创建 -> 待支付 -> 支付处理中 -> 已支付 -> 权益发放中 -> 已生效
                         |              |
                         v              v
                       失败/重试       履约失败/联系客服
```

用户必须能看到订单号、支付渠道、金额、支付结果、权益生效时间和安全摘要错误；不能因刷新页面重复扣款或重复激活套餐。

#### 3.3.3 订单和账单

- 订单列表支持按状态、时间和套餐筛选。
- 订单详情展示商品快照、价格、折扣、支付流水摘要、退款状态和权益关联。
- 提供账单/收据下载入口；税务发票状态单独展示，不能把收据冒充发票。
- 支付成功但权益尚未生效时展示“正在发放权益”，提供刷新和联系客服入口。

### 3.1 页面区域

```text
顶部：当前套餐、存储用量、流量用量、升级入口
中部：拖拽/选择/粘贴上传区域
设置：可见性、文件夹、相册、标题、标签、过期时间
队列：文件名、缩略图、进度、状态、重试、取消
底部：链接复制和批量操作
```

### 3.2 文件状态

| 状态 | UI 表现 | 用户操作 |
| --- | --- | --- |
| waiting | 等待上传 | 取消 |
| uploading | 进度条和速度 | 暂停/取消 |
| processing | “正在生成图片链接” | 查看详情 |
| ready | 成功图标和复制按钮 | 复制链接、查看、删除 |
| failed | 错误码和原因 | 重试、移除 |
| rejected | 审核/格式拒绝原因 | 查看规则、移除 |

前端不得因为上传 HTTP 请求成功就显示“完成”；必须根据媒体状态或处理查询接口显示 `ready`。

### 3.3 配额提示

上传前展示：

- 当前文件大小
- 上传后预计使用量
- 当前剩余空间
- 今日剩余上传次数
- 当前 Token/API 配额（如果使用 Token）

超额提示必须明确原因，例如“空间不足 120 MB”，并提供删除旧文件、清空回收站或升级套餐入口。

## 4. 媒体库

### 4.1 网格卡片

卡片展示：

- 缩略图
- 文件名/标题
- 尺寸和大小
- 状态标签
- 可见性
- 选择框
- 快捷复制 URL

不要在网格中加载原图；缩略图失败时展示可重试的占位状态。

### 4.2 批量操作

批量操作必须显示选择数量和影响范围：

- 移动到文件夹
- 添加到相册
- 修改可见性
- 创建分享链接
- 下载
- 移入回收站

永久删除、批量公开和批量下载必须二次确认。操作结果使用 `succeeded`、`failures`、`skips` 分组展示，不能只显示一个“操作成功”。

## 5. 媒体详情页

页面分为四个区域：

1. 预览：缩略图、中图、原图切换。
2. 链接：URL、Markdown、HTML、BBCode、原图和各 Variant。
3. 信息：文件名、MIME、大小、尺寸、哈希、上传时间、可见性。
4. 操作：编辑、创建分享、下载、删除、恢复。

链接组件规则：

- `null` Variant 显示“处理中”，不显示失效 URL。
- 每个链接独立复制，并提供复制成功反馈。
- Markdown/HTML 中的标题来自用户标题，必须进行转义。
- 原图下载和批量下载根据套餐权益显示或禁用。
- 复制链接不应把密码或 Token 写入剪贴板之外的日志。

## 6. Personal API Token 页面

### 6.1 Token 列表

表格列：

```text
名称 | 前缀 | 基础能力 | 扩展 Scope | 状态 | 过期时间 | 最近使用 | 操作
```

完整 Token 不在列表显示。创建成功后显示一次性安全提示框：

```text
请立即复制 Token。离开此页面后无法再次查看完整 Token。
```

### 6.2 创建表单

表单包含：

- Token 名称（必填）
- 过期时间（可选）
- 可选 Scope：媒体列表、用量、Webhook
- 风险提示：Token 等同于个人 API 凭证

上传、获取自己图片链接和删除自己图片是固定基础能力，不显示为可取消的复选框。

### 6.3 撤销和轮换

- 撤销前显示最近使用时间和来源 IP。
- 轮换明确提示旧 Token 会立即失效。
- 删除/撤销成功后清除前端内存中的 Token。
- Token 页面不能把完整 Token 写入 URL、LocalStorage 或埋点事件。

## 7. 用量和套餐页面

用量卡片：

```text
存储空间：已用 / 总量
外链流量：本周期已用 / 总量
每日上传：今日已用 / 上限
API 上传：本周期已用 / 上限
图片处理：本周期已用 / 上限
```

每张卡片必须显示重置时间或“长期额度”。套餐比较只突出差异，不隐藏 Free 的已拥有能力。

## 8. 回收站和删除体验

- 删除先进入回收站，不立即物理删除。
- 回收站显示预计永久删除时间。
- 恢复前检查原对象和用户当前配额。
- 永久删除明确说明原图、派生图和分享链接都会失效。
- 回收站内容继续计入存储用量，页面必须明确提示。

## 9. 发现页

- 首次加载先请求 `/api/v1/discovery/status`；关闭时显示后台配置的关闭说明，不继续请求 feed。
- 默认只请求 approved、ready、public 媒体。
- 投稿按钮受 `submissions_enabled` 控制，关闭时显示“当前暂停投稿”。
- 瀑布流使用分页或游标，不一次加载全部数据。
- 支持随机、最新、热门排序，但排序参数必须由后端白名单控制。
- 卡片提供举报入口，不展示 GPS/EXIF 等隐私信息。
- 未登录用户只能浏览公开内容，不能访问私有媒体。

发现页状态：

| 状态 | 用户端行为 | 后台行为 |
| --- | --- | --- |
| enabled | 展示内容和投稿入口 | 审核新投稿和举报 |
| submissions_closed | 展示已有内容，不显示投稿入口 | 继续处理已有举报 |
| disabled | 展示关闭说明，不请求内容列表 | 仍可审核、举报和恢复 |

举报弹窗必须提供原因、补充说明和提交结果。用户不能看到被举报人的私密信息，管理员处理结果通过通知反馈必要信息。

## 10. 管理端页面

### 10.1 发现页设置

- 总开关：启用/停用发现页
- 投稿开关：允许/禁止新图片投稿
- 审核模式：人工、自动、混合
- 默认排序：最新、随机、热门
- 举报阈值：达到阈值后自动进入人工复核
- 关闭提示文案

修改设置前显示影响范围；停用发现页不影响用户私有媒体和已有私有分享链接。

### 10.2 举报处理工作台

列表支持按状态、原因、媒体、用户、时间筛选。详情展示媒体预览、用户摘要、举报历史、审核结果和相关处罚记录。

处理动作：

- 驳回举报
- 隐藏图片
- 删除图片
- 恢复图片
- 限制用户投稿
- 限制用户上传
- 暂停账户
- 封禁账户

每个动作必须填写原因；封禁、永久删除和批量操作必须二次确认并写入审计日志。

处罚弹窗必须显示：

- 处罚对象和影响范围
- 当前违规图片和举报原因
- 处罚级别：限制投稿、限制上传、暂停、封禁
- 处罚期限
- 是否立即隐藏已有公开图片
- 是否允许申诉

不能把“举报次数”直接展示成自动封禁依据；达到阈值时显示“需要人工复核”。

### 10.3 用户申诉

被处罚用户在个人中心看到：

```text
处罚类型 | 原因 | 生效时间 | 到期时间 | 状态 | 申诉入口
```

申诉表单包含说明和证据附件。提交后显示 `pending/reviewing/upheld/overturned/adjusted` 状态，并通过通知告知最终结果。

管理端优先复用 Generic Resource：

- 套餐
- 套餐权益
- 文件夹/相册
- 广告位/广告素材
- 举报
- 存储节点

使用 Custom Page：

- 运营仪表盘
- 全局媒体审核
- 用户媒体详情
- 失败任务中心
- 流量和收入分析

管理员页面必须显示数据来源时间和筛选条件；涉及用户媒体、额度、封禁、审核和永久删除的操作必须显示审计提示。

## 11. 空状态、错误和可访问性

- 空媒体库：说明如何上传，并提供上传按钮。
- 无搜索结果：显示当前筛选条件和清除筛选按钮。
- API/网络错误：显示 request ID 和重试按钮。
- 403：说明权限或套餐原因，不泄露资源是否存在的敏感信息。
- 429：显示限流/配额原因和下次可重试时间。
- 所有上传进度、状态颜色和按钮都要有文本或 aria-label，不依赖颜色表达唯一含义。
- 键盘可以完成文件选择、复制链接、删除确认和 Token 撤销。
