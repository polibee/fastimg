# FastImg 内容治理策略

本文档用于后台审核员和系统实现。它定义默认处理建议，最终动作仍需结合当地法律、版权通知、用户申诉和站点运营政策。

## 1. 违规分类

| 类型 | 示例 | 默认严重级别 |
| --- | --- | --- |
| illegal | 明显违法内容、恶意攻击、诈骗素材 | critical |
| sexual/minor | 未成年人性相关内容或疑似内容 | critical |
| violence | 极端暴力、恐怖主义宣传 | critical/high |
| copyright | 版权方投诉、盗用商业素材 | high/medium |
| privacy | 身份证、联系方式、定位等敏感信息 | high |
| harassment | 针对个人的骚扰、威胁、曝光 | high/medium |
| spam | 广告刷屏、恶意跳转、批量垃圾图 | medium |
| malware | 恶意脚本、伪装文件、钓鱼页面素材 | critical/high |
| other | 不属于以上类别 | manual_review |

## 2. 严重级别和默认动作

### Critical

适用于明显违法、未成年人性内容、恶意软件、诈骗或严重安全风险：

- 立即停止公开展示
- 暂停相关媒体访问策略
- 账户进入 `suspended` 或 `banned` 候选状态
- 创建人工复核任务
- 保留必要证据和操作审计
- 不因自动规则直接永久删除证据，除非法律或安全策略要求

### High

适用于严重隐私、威胁、重复侵权和大规模滥用：

- 立即隐藏发现页展示
- 暂停投稿或 API 上传
- 进入人工复核
- 视历史违规次数决定是否暂停账户

### Medium

适用于一般版权争议、骚扰和垃圾内容：

- 暂停发现页展示
- 通知用户整改或补充说明
- 允许在期限内申诉
- 重复违规时升级处罚

### Low/Review

适用于信息不足、误报可能性较高的内容：

- 保持 `manual_review`
- 不直接封禁账户
- 可以暂时关闭公共展示

## 3. 账户违规累计策略

累计违规不能简单按举报数量计算，至少综合：

- 已确认的违规动作数量
- 违规严重级别
- 是否重复同类违规
- 是否存在恶意规避或批量上传
- 历史处罚是否仍在有效期
- 用户申诉是否成立

建议默认升级路径：

```text
首次 medium -> 隐藏媒体 + 提醒整改
重复 medium -> 限制投稿/上传
首次 high   -> 隐藏媒体 + 人工复核 + 暂时限制
重复 high   -> suspended
critical    -> 立即隐藏 + suspended/banned 候选 + 人工复核
```

系统不得仅依据“被举报次数”自动永久封禁账户。

## 4. 举报处理流程

```text
提交举报
  -> 参数和频率校验
  -> 举报去重
  -> 计算风险级别
  -> 自动隐藏或进入人工队列
  -> 审核员处理
  -> 执行媒体/账户动作
  -> 写入审计和通知
  -> 开放申诉
```

举报提交约束：

- 未登录用户可以举报公开媒体，但需要更严格的频率限制。
- 登录用户可以看到自己的举报提交结果，但不能看到被举报人的隐私资料。
- 同一用户、媒体、原因在活动周期内重复提交返回原举报 ID。
- 举报描述和证据附件必须做大小、格式和恶意内容校验。
- 举报人不能直接决定处罚结果。

## 5. 后台审核员工作台

审核列表至少显示：

```text
风险级别 | 举报原因 | 媒体预览 | 媒体所有者 | 历史违规 | 当前处罚 | 截止时间 | 状态
```

审核详情显示：

- 图片预览和原图访问权限
- 图片基本信息和公开链接状态
- 举报历史和重复举报合并情况
- 用户历史处罚和申诉结果
- 关联媒体数量和近期上传行为
- 可执行动作及其影响范围

审核员不能直接查看不必要的私密媒体原图；敏感内容应默认模糊或低分辨率预览，并通过单独权限查看原图。

## 6. 证据和审计

- 证据记录使用对象存储私有路径或不可公开的引用。
- 审计记录保存目标、动作、原因、证据引用、操作者、时间、请求 ID 和前后状态。
- 处罚记录不能被编辑覆盖，只能追加撤销、恢复或调整动作。
- 证据保留期限由站点配置，但订单、审计和法律保留记录不能因普通用户删除而丢失。
- 日志中禁止写入 API Token、分享 Token、密码和完整私有 URL。

## 7. 申诉规则

- 每个处罚目标只允许一个未完成申诉。
- 申诉必须包含说明，可选附加证据。
- 申诉处理人不能是原处罚操作者，除非管理员明确允许并留下理由。
- 申诉结果为维持、撤销或调整处罚。
- 撤销处罚不会自动恢复已永久删除的对象。
- 申诉结果通过站内通知反馈用户。

## 8. 处理时限建议

| 队列 | 目标响应时间 |
| --- | --- |
| critical | 15 分钟内进入人工队列 |
| high | 4 小时内处理 |
| medium | 1 个工作日内处理 |
| low/review | 3 个工作日内处理 |
| appeal | 3 个工作日内完成首次响应 |

这些是运营目标，不是绕过安全检查的超时策略；超时内容仍不能自动公开或自动解封。

## 9. 测试要求

- 重复举报返回原举报记录。
- 达到举报阈值只创建复核任务，不自动永久封禁。
- critical 内容可以自动隐藏并进入人工复核。
- 审核员没有处罚权限时无法执行封禁。
- 原处罚操作者不能处理自己的申诉。
- 停用发现页不影响私有媒体和用户分享链接。
- 恢复图片必须重新检查审核状态和对象是否存在。
